## Обзор проекта

**ImpulseRC Driver Fixer** — специализированная утилита для **Windows**, созданная для решения проблем с USB-драйверами полётных контроллеров, используемых в FPV-дронах. Она особенно полезна в ситуациях, когда контроллер физически подключён к компьютеру, но Betaflight Configurator или другая программа не может корректно определить устройство.

Утилита автоматизирует процесс поиска подключённого устройства и установки подходящего драйвера. Это избавляет пользователя от необходимости вручную искать устройство в Windows Device Manager, определять его USB VID/PID и самостоятельно заменять драйвер.

Driver Fixer часто применяется при работе с контроллерами на базе **STM32**, особенно когда требуется перевести устройство в **DFU mode** для прошивки firmware. После исправления драйвера совместимый конфигуратор получает возможность обнаружить загрузчик и выполнить дальнейшие операции с полётным контроллером.

## DFU Mode и Betaflight

При обновлении firmware многие полётные контроллеры переводятся в **DFU (Device Firmware Upgrade)**. В этом режиме устройство определяется системой иначе, чем при обычном подключении через виртуальный COM-порт.

Если Windows назначила неподходящий драйвер, **Betaflight Configurator** может не увидеть контроллер в DFU. В результате пользователь не может перейти к прошивке даже несмотря на то, что устройство корректно находится в bootloader mode.

ImpulseRC Driver Fixer помогает исправить такую ситуацию. После успешной установки драйвера DFU-устройство должно корректно определяться системой, после чего прошивка выполняется уже через соответствующий конфигуратор.

## Когда использовать Driver Fixer

| Проблема | Применение |
|---|---|
| **DFU не определяется** | Проверить и исправить драйвер загрузчика |
| **Betaflight не видит DFU** | Восстановить корректное USB-подключение |
| **Unknown Device** | Проверить назначенный Windows драйвер |
| **После смены USB-порта** | Повторно проверить обнаружение устройства |
| **STM32 Bootloader** | Исправить проблемы с драйвером DFU |
| **Firmware Flashing** | Подготовить корректное соединение перед прошивкой |

Если контроллер вообще не появляется в Windows, причиной может быть не драйвер, а USB-кабель, разъём, питание или сам полётный контроллер. Driver Fixer не исправляет аппаратные неисправности.

Также важно использовать USB-кабель с передачей данных: кабели, предназначенные только для зарядки, не позволяют компьютеру установить соединение с FC.

## Работа с FPV-контроллером

Перед использованием утилиты рекомендуется закрыть другие программы, которые могут обращаться к полётному контроллеру. Затем устройство подключается к компьютеру и при необходимости переводится в bootloader/DFU mode.

ImpulseRC Driver Fixer выполняет поиск подходящего устройства и исправляет конфигурацию драйвера. После завершения процесса можно повторно запустить Betaflight Configurator и проверить наличие **DFU** среди доступных подключений.

Для обычного COM-подключения и DFU Windows использует разные интерфейсы, поэтому успешное обнаружение контроллера в обычном режиме ещё не означает, что DFU-драйвер настроен правильно.

## Быстрый старт

1. Подключите FPV-полётный контроллер к компьютеру.
2. Используйте USB-кабель с поддержкой передачи данных.
3. При необходимости переведите FC в **DFU / Bootloader Mode**.
4. Закройте Betaflight Configurator и другие программы, использующие устройство.
5. Запустите **ImpulseRC Driver Fixer**.
6. Дождитесь обнаружения подключённого контроллера.
7. Позвольте программе выполнить исправление USB-драйвера.
8. После завершения отключите и повторно подключите устройство.
9. Запустите Betaflight Configurator.
10. Проверьте, что контроллер корректно определяется в DFU или требуемом режиме.
