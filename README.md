# .github
ImpulseRC Driver Fixer — компактная утилита для Windows, предназначенная для автоматического исправления USB-драйверов полётных контроллеров FPV-дронов. Помогает восстановить подключение устройств в DFU и других режимах, чтобы Betaflight Configurator и другие инструменты могли корректно обнаруживать контроллер.
